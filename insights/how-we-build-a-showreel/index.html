How We Build a Showreel That Actually Works

A showreel is not a greatest-hits playlist. It is a first sentence. In the first eight seconds a client should know who we are, how we move, and whether they want to sit through the rest.

We start with a single through-line: tempo. Then we cut for faces, then for light, then for the one shot that proves we can hold a room. Everything else is decoration.

The Cristian reel is rebuilt twice a year. Old work drops out the moment it no longer matches the work we want next. That is the whole method.
